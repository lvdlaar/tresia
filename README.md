# Tresia

Kleine website met custom styling en JavaScript.

## Bestanden
- `tresia.css`
- `tresia.js`

## Lokaal openen
Open de websitebestanden in je browser of serve de map met een simpele static server.

Voorbeeld met Python:

```bash
python -m http.server 8000
```

Ga daarna naar `http://localhost:8000`.
